

# RulesEngine

Proyecto bifurcado (fork) de [RulesEngine](http://rulesengine.codeplex.com) - [athoma13](http://www.codeplex.com/site/users/view/athoma13).

Rules Engine es un proyecto en C# para .NET que valida la lógica de negocio definiendo una serie de reglas para sus clases de datos. Las reglas se definen utilizando una clase auxiliar con interfaz fluida (validación fluida), y no decorando sus objetos existentes con atributos, desacoplando así la lógica de validación de las clases de datos (o de dominio). vía [RulesEngine](http://rulesengine.codeplex.com)

[Dirección del proyecto original](http://rulesengine.codeplex.com/)

[Enlace en NuGet](https://www.nuget.org/packages/athoma13.RulesEngine)

### Instalación

	Install-Package athoma13.RulesEngine
